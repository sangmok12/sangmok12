# 임상목 | 데이터 중심 Java 웹 개발자

공공기관 대외 웹서비스를 운영하며 Java/JSP 기반 기능 개발, 데이터 관리, Open API 연계를 담당하고 있습니다. 반복되는 업무를 자동화하고, 필요한 데이터를 사용자가 실제로 활용할 수 있는 서비스로 만드는 데 관심이 많습니다.

- 한국산업기술진흥원 대외시스템 개발·운영 3년차
- 국가기술은행(NTB) 메인 담당
- 요구사항 분석부터 개발, 테스트, 운영 반영까지 수행
- 한국산업기술진흥원 우수사원 표창
- 한국방송통신대학교 컴퓨터과학과 졸업

## 주요 프로젝트

- OpenAI API를 연동해 기술·경력·직무·희망조건별 적합도와 근거 제공
- 강점·보완점·지원 전략을 정리하고 React 화면에서 분석 결과 확인

`Java 21` `Spring Boot` `React` `OpenAI API` `Playwright` `Tesseract OCR` `Apache Tika`

## 경력

### 애니파이브 | ICT 2팀 선임연구원

`2024.01 - 재직 중`

한국산업기술진흥원(KIAT)의 대외 웹서비스를 개발·운영하고 있습니다.

- 국가기술은행(NTB) 메인 담당자로 기능 개선, 오류 대응, 운영 이슈 처리
- Java/JSP 기반 기존 소스 분석과 기능 개발·수정
- 기술정보 등록·수정·공개 데이터 및 Open API 연계 데이터 운영
- PostgreSQL, Tibero, Oracle 환경에서 SQL을 활용한 데이터 조회·정제·수정·추출
- MyBatis 데이터 처리 로직과 SQL 분석·수정
- 웹·WAS·DB 장애 원인 분석 및 조치
- 요구사항 분석, 개발, 테스트, 폐쇄망 배포 절차에 따른 운영 반영

### 주요 개선 경험

- 비밀번호 5회 실패 시 접속 제한과 중복 로그인 방지 기능 개발
- SHA-1 기반 암호화를 SHA-256 방식으로 개선
- 첨부파일 다운로드 사유와 사용자 직군을 DB에 기록하는 기능 개발
- 개인정보 및 금칙어 등록 방지를 위한 이지서티 API 연계
- SQL Injection과 파라미터 위변조 등 웹 취약점 보완
- 웹 접근성·호환성 점검과 SSL 인증서 교체
- CSV·Excel 대량 데이터 입출력 및 운영 데이터 처리
- HSSF의 65,535행 제한을 XSSF 전환으로 해결
- 수직 탭 문자로 인한 Excel 파일 손상 오류 해결
- 압축파일 내부 폴더 구조로 발생한 첨부파일 처리 오류 개선
